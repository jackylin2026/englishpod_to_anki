# A directory the corpus's owner declares is not a lesson

A corpus holds material that belongs to no lesson. `ENGLISHPOD主持人对话文本/`, in the corpus root, holds 178 host-transcript PDFs, which the epic's rejected list already puts outside the card design, and discovery cannot tell them from a lesson's: the directory holds PDFs, so every corpus run found it, could not choose a file from it, and reported it as one more skipped lesson. The corpus's owner can now name such a directory in `.englishpodignore`, at the root a stage is pointed at, by its own name or by its path from that root, and the walk neither descends into it nor reports it. An ignored directory is not a lesson the tool declined: it is one the corpus was declared not to hold, which is why nothing about it is reported and why `CONTEXT.md` keeps the two words apart.

This narrows ADR-0006's "the layout is the list, not a hand-maintained one" rather than contradicting it, and the direction the two lists fail is the reason. A hand-maintained list of *lessons* goes stale by silently omitting lessons that do exist: the list looks complete, the corpus grows, and nothing says a lesson was missed. A hand-maintained list of *exclusions* goes stale in the other direction — an entry that no longer matches anything excludes nothing, so the directory it named is discovered again and appears in the run's report, which is exactly the behaviour visible before this existed. The included set fails silently and the excluded set fails loudly, so only the excluded set is safe to write down.

Matching is exact, a name or a path, with no globs and no prefixes. Every shape that would make the file more convenient to write — `0*`, `英语*`, a prefix — buys that convenience with the risk of over-matching, and over-matching is the one direction that cannot be allowed to fail quietly: it takes lessons out of every run and mentions none of them. A file per directory, .gitignore-style, was rejected for the same reason at a larger scale: negation, nested files and `**` spread the answer to "why did this lesson vanish" across several files, to buy power nobody asked for.

The costs are four. `.englishpodignore` is the one file the tool asks of a corpus it otherwise reads where it lies, so a corpus copied without it behaves differently — loudly, in the report, but differently. Only the file at the directory a stage is pointed at is read, so pointing at one batch directory does not consult the corpus root's file. An entry broad enough to name a batch directory takes the ten lessons inside it, and the combined PDF that would have been reported in their place, out of the run in silence: the walk prunes before anything asks what a directory is, which is what makes an ignored directory invisible rather than merely skipped, and it is the same property that makes a mis-written entry invisible. And excluding a batch's lessons one by one, rather than the batch itself, promotes the batch directory to a lesson in their place — it then holds a combined PDF and no lesson beneath it, which is what a lesson directory looks like — so that case is reported rather than silent.
