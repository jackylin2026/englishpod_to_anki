# Cross-check each lesson's dialogue against the print transcript

The corpus carries a second printing of most of its dialogue — a condensation of two columns to a page, holding dialogues for 329 of the first 330 lessons and no vocabulary at all — and nothing in the tool had ever read it. A parsing regression, a page dropped from a scan's Markdown, a column read in the wrong order, could only be noticed by opening the lesson and the print side by side. `preprocess` now takes `--print-transcript`, splits that document into one dialogue per lesson, and compares each lesson's dialogue with the print's reading of it.

The check is preprocess's rather than build's for two reasons. The transcript is a document to be read, and reading documents is what this stage does: the epic had it split there, and ADR-0002 foresaw the shape — "a diff between two Markdown files rather than a PDF-to-PDF comparison". And what the check is for is a *parsing* regression: it is the extraction that is in question, and the stage that extracts is the one whose output should be checked. It rides on the same pass: a lesson a run works on is a lesson it checks, and a lesson the run skips is not checked, because there is nothing there to compare with. What a disagreement does is be reported: the run names the lesson on stderr and counts it at the end, and neither the Markdown, nor the print's file beside it, nor the card built later is changed by it. The tool does not prefer one printing to the other, because it is not the tool's to prefer.

The print's version is written beside the lesson's own Markdown (`englishpod_D0108.transcript.md`), so that a person looking at a warning has the two readings in one directory, and so that a lesson's directory is the whole answer to "what is this lesson, and what does the other printing say it is". That puts two Markdown files in a directory that used to hold one, and the two are told apart by name: the file the tool writes for the print is named for the lesson's own Markdown, and the lesson's is the one not carrying that name. The other rule — the lesson's Markdown is the one whose title carries a lesson code, and a transcript file carries none — was rejected after it was written, because it breaks two things that have to keep working: `tests/fixtures/corpus/0001/` holds a lesson's Markdown with no title code at all, which every stage must still report as "carries no lesson code", and a hand-written Markdown can be dialogue and nothing else, which is exactly the shape a transcript file has. The name is a fact about what this tool writes and never reads back as a lesson; "carries no lesson code" is not, because a Markdown can be the lesson's and not carry one yet.

Reading the print is not reading a lesson. Its pages are printed in columns, so a line belongs to the column it sits in rather than to the row it shares a height with; its page number is printed at the foot, in the gutter between the columns, and is dropped before the columns are found, since leaving it in cuts the gutter in two. Its lessons are matched by the number the code prints rather than by the whole code, because the print's printing of a code is its own: its level letters differ for seven lessons (it prints `C0003`…`C0009` where the corpus's documents say `B0003`…`B0009`), and two of its codes carry three digits rather than four — `(D046)` is lesson 0046 and `(C068)` is 0068. It is the number that says which lesson is meant, as it is for a lesson read out of a batch's PDF (ADR-0008), and one lesson (0168) it prints no code for at all is the one lesson of the first 330 it does not cover. Its titles are set larger than its dialogue (12pt against 10.5, with the page numbers at 9), which is what keeps a title out of the dialogue: the print fills a column and breaks it wherever it fills, so a title of its two-line kind is often split across a column break, its first line left at the end of the lesson before — measured, a reading that keeps the print's title rows as dialogue reports 117 disagreements where this one reports 32. A document that carries a `Key Vocabulary` table is refused rather than read: the print has no vocabulary, so a document with vocabulary is lessons, and pointing the flag at the wrong PDF should say so at once.

Two dialogues are the same dialogue when the letters and digits they are made of, lowercased and in order, are the same. Nothing finer survives the second printing: its text layer drops the apostrophes contractions were typed with (`dont`, `ill`, `im`), its spacing runs words together (`twofor-` `one`, `A:It`, `Yeah&Here`), its justifier stretches the spaces inside a line, and its hyphenation breaks words the lesson's own document did not. A comparison that counted those would report most of the corpus. What it does count is a word added, dropped or moved — which is what a parsing regression looks like. Measured against the corpus, 297 of the 329 lessons it covers agree with it and 32 disagree; of those 32, nine differ by a line or more (a line missing, a turn assigned to the wrong speaker, an OCR line lost — the things the check is for), six by a word or two, and seventeen by a letter or two of the print's own typos. Six of the old thirty-eight are gone: a label a lesson's own column printed over two rows is read as one label now, and those six lessons read as the print reads them. The print's own printing accounts for some of what is left in a way nothing can untangle: one of its pages repeats a lesson's dialogue before the title it belongs to (0180's block reads with 0181's dialogue in it), others carry a stretch the lesson's own document does not, and lesson 0319's page prints a word without its first letter (`ell please` for `well please`), which no reading of the lesson puts back. That lesson carries a second print-side difference, which only shows now that the lesson's own reading is right: the print prints its `Older gentle- man:` as one row of three words, where its reader finds a label of no more than two, so the turn never opens in the print's file while the lesson's own Markdown carries it. Thirty-two warnings on a corpus-wide run is the corpus's own noise rather than a clean bill of health, and that is the honest shape of checking one printing against another.

The costs are three. A lesson the print covers now holds a second Markdown file, which is clutter in a directory that a person reads. `preprocess` now reads the Markdown it used to leave alone unread, so a lesson whose Markdown cannot be read is reported as skipped when a transcript is given, where it used to count as "already had a Markdown file" — the same verdict `build` has always given it, and the price of checking the file that is really there rather than the one the run would have written. And the print's titles are recognised by the size they are set in, which a reading with no sizes to give would not see: a page read back off its own picture by the OCR pass has no type to measure, though the print transcript is always a PDF whose text layer carries one. A reading without sizes falls back to reading the titles as dialogue rather than failing, which costs warnings rather than lessons.
