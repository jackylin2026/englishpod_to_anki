# A word is transcribed once, and written down

The answer side of a card has carried an empty `Phonetic symbols` field since the card's design was implemented, and it is the last of the design's six fields with nothing in it. It now holds IPA for the lesson's single-word vocabulary terms — both tables, so a term has a transcription wherever on the card it appears — and nothing at all for a phrase, which has no one pronunciation to give and whose guess would be worse than a blank. A word is resolved in a fixed order: the file the repository keeps, then the offline dictionary (`cmudict`, which this tool already reads to settle de-hyphenation, and which supplies a pronunciation for 2298 of the corpus's 2485 distinct single-word terms), then the free online dictionary at `api.dictionaryapi.dev`, then Wiktionary. Whatever a lookup resolved is written into `src/englishpod_to_anki/transcriptions.tsv` as it is resolved, and read back from there: a word is looked up online at most once in the tool's lifetime, a re-run needs no network, and the same lesson produces the same card whether the network is there that day or not.

The file is read *before* any dictionary is asked, which is the decision most worth writing down. It is what makes the file the learner's instrument: an entry written by hand wins over every source, including the offline dictionary, so a word `cmudict` mis-stresses can be corrected there and stays corrected. Had the offline dictionary been consulted first, there would be no way to correct it at all, because its answers are deliberately never written to the file — the mapping from ARPAbet to IPA is code, and if its answers were cached then improving the mapping would reach no word that had ever been built. A word the offline dictionary knows is therefore still never looked up online (the file has no entry for it, so the offline dictionary answers it), and a word in the file is never looked up again in any case. A word no dictionary has is written down as `-`, which is not a transcription and cannot be mistaken for one: it records that the word *was asked about* and that nobody had it.

Which leaves the thing the sources cannot settle between themselves, and which the tests are mostly about: what a service's silence means. A service that answers and has no transcription for a word is saying something about the word, and that is worth writing down; a service that cannot be reached is saying something about the network, and writing that down would fix a blank into the committed file for good — the very thing the file exists to prevent. So only an answer settles a word: a miss is recorded only when every service was actually asked, and a service that fails (a connection that never comes up, a 5xx, a 429) is struck off for the rest of the run rather than asked once per word — a corpus run pays one timeout, not one hundred and eighty-seven. The word is reported either way, the card is built either way, and the run exits zero: `C0108: no transcription for newsagent` names what is missing, and the next run asks again. The offline-only run is the same rule taken to its end, and it has a test of its own: a run that asked nobody has learned nothing about the word, and must not write down that nobody had it.

A build reaching the network by default is a change in this tool's habits, and is deliberate where the OCR pass is opt-in. That pass is a page-by-page bill against a key its owner keeps; this one is two free services that need no key, and the alternative — resolving phonetics only when asked for, in a pass of its own — would leave the field empty in every card imported by someone who did not know to ask. What keeps the default safe is that the traffic is one-time and tiny: the 187 words the offline dictionary lacks, once for the whole corpus, and after that the file answers everything. A run that must not touch the network at all says so with `--offline`, and one that must reach different dictionaries says so with `--dictionary-url` and `--wiktionary-url`.

What the sources say is not one notation, and the card writes one. The three dictionaries spell the same sounds with different letters — a script `ɡ` U+0261 and a Latin `g`, an `r` and the turned `ɹ`, a length mark that American English has no use for — so what a dictionary answers is translated into the house's letters on the way into the file. What is *not* done is re-spelling: the online services answer with a British transcription where that is the one they have, and turning `/ˈdɒdʒi/` into `/ˈdɑdʒi/` is not translating letters but answering a different question — the vowel a speaker of American English would use is a fact about the accent, not about the notation, and the tool does not guess at it. Wiktionary is asked for its American transcription where it has one, which is where that preference belongs.

Measured over the learner's corpus, the whole of this is 2485 distinct single-word terms, 187 of which the offline dictionary has never heard of — the corpus's own coinages and misreadings (`goomsman`, `housewaming`, `bizzard`, `sweeentie-pie`), the compounds (`two-for-one`, `bite-sized`, `eco-system`), the initialisms (`cpr`, `icu`, `gmat`, `nhl`, `tmi`) and a handful of proper nouns. On the day the corpus was first built through this, the free online dictionary was unreachable from this machine — a read that timed out on its first call, after which it sat out the run and said so once — and Wiktionary answered 63 of the 187: `undies` `/ˈʌn.dis/`, `bling` `/blɪŋ/`, `churro` `/ˈt͡ʃʊroʊ/`, `bodybuilder` `/ˈbɑ.diˌbɪl.dər/`. The other 124 were left blank and reported, and — this being the rule working rather than failing — *not* written down: the service that might have had them was never asked, so nothing about them was settled, and each run asks again until it answers. Had the run written them down as words nobody has, a serving dictionary could never fill them in. A second build of the same corpus, offline, made the same 352 notes byte for byte, which is the property the whole arrangement exists for. Reading that corpus asked one change of the reader: a page may hang the accent off the transcription itself rather than pass it as an argument (`/ˈkæri ˌɑn/<a:US>`), and the first build read the markup into the file along with the symbols. It is now found inside the argument rather than taken as the whole of it, and the file's bad entry was corrected the way any wrong entry is: the line was struck out and the word asked for again.

The offline dictionary's stress values are left exactly as it gives them, which is the other place the tool declines to improve on a source. `cmudict` marks the stress of a compound poorly: `overstocked` comes back carrying two primary stresses, and 25 of the corpus's 2263 words are like it — the initialisms (`fbi`, `crm`), the compounds (`coworkers`, `goatee`, `forthright`). Keeping the first primary and demoting the rest is right for some of them and wrong for others, and keeping the last one is right for a different set; neither is a rule, so neither is applied. It is recorded here rather than fixed because it is exactly the kind of thing the file is for: a word that comes out wrong is corrected once in a readable file, and the correction outlives every lookup. The same reasoning covers the stress mark's *placement*, which is computed rather than taken — it goes before the stressed syllable's onset, the longest run of consonants English lets a syllable begin with, which is what makes `inventory` `/ˌɪnvənˈtɔri/` and not `/ˌɪnvəntˈɔri/`. It gets the ordinary word right and the occasional one wrong (`absurd` comes out `/əˈbsɝd/` where a dictionary writes `/əbˈsɝd/`), and those are the file's business too.

What settled the choice of offline dictionary was the learner's own card having come from it. The hand-built card for lesson 108 carries four transcriptions; `cmudict` plus this mapping reproduces three of them exactly — `/ˈɡɔri/`, `/dɪˈzæstrəs/`, `/ˈplʌndʒ/` — down to the script `ɡ` (U+0261) and the plain `r`, which is not a thing two dictionaries would agree on by accident. The fourth, `inventory`, is stressed on its first syllable there and its second here, which is their source's choice rather than an error in this one; the reference was treated as the card's *shape* rather than its content, exactly as it was for the blanks (ADR-0003). The card built from that lesson today carries eleven entries, and `gory` is not among them — the term the corpus prints is the phrase `gory details`, which is one of the two kinds of term this field leaves alone.

Three other ways were put to this and set aside. A cache per lesson rather than a file of words was the first: it would ask the same word once per lesson that carries it, and a word shared by a dozen lessons is not a rare thing in a corpus of a vocabulary course's own material. A keyed dictionary service — Merriam-Webster's, say, whose API would answer better than the free one — was rejected for the same reason the OCR pass is opt-in: a corpus-wide build would then need a secret in `.env` and a bill nobody asked for, and the free service plus Wiktionary covers what the offline dictionary does not. Pulling in a package that maps ARPAbet to IPA was tempting and rejected: the mapping is a table of forty entries, the packages that do it carry their own dictionaries and their own opinions about notation, and the house wants the letters the learner's own card is written in. And splitting a compound the dictionaries do not have into words they do — `two-for-one` as `two`, `for`, `one` — is the one thing the field's own rule forbids: an invented transcription for a term nobody transcribes is worse than an empty field, and the word is reported instead.

What this costs is mostly honesty about files. A `build` now writes one: the stage that "touches nothing" writes the transcriptions file, because the ticket that asked for the lookups asked for them to be remembered. A file that cannot be written — a read-only install, a directory the run cannot write into — costs the next run a lookup rather than this one a lesson, so it is reported once at the end of the run and the cards are made anyway. A file that cannot be *read*, a line that is not a word and a transcription separated by a tab, stops the run before it starts and names the line: a correction silently ignored is worse than one refused. And the file is rewritten from its entries on every save, so a comment written into it by hand is not kept — which the header line it is rewritten with says, since a person opening the file is who that line is for.
